Frequently Asked Questions

How do I generate my first CI/CD pipeline?

Go to the main page, describe your requirements in the input field, and click "Generate Code". For example, type "Create a GitHub Actions workflow for a Node.js application".

What file formats are supported for upload?

We support PDF, TXT, MD, YAML, YML, and JSON files. Maximum file size is 10MB.

How do I get an API key?

API keys are automatically generated when you first visit the application and are stored in your browser's local storage.
