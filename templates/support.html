Frequently Asked Questions

How do I generate my first CI/CD pipeline?

To generate your first CI/CD pipeline, go to the main page and describe your requirements in the input field. For example, you can type "Create a GitHub Actions workflow for a Node.js application" and click "Generate Code". The AI will create a complete pipeline configuration for you.

What file formats are supported for upload?

CI/CD Helper supports the following file formats: PDF, TXT, MD, YAML, YML, and JSON. The maximum file size is 10MB. These files are stored in your personal library and can be referenced when generating new pipelines.

How do I get an API key?

API keys are automatically generated when you first visit the application. If you need a new API key, you can generate one through the API endpoint. Your API key is stored in your browser's local storage and is required for all API calls.

Can I use CI/CD Helper for commercial projects?

Yes, CI/CD Helper can be used for both personal and commercial projects. The generated code follows industry best practices and can be customized to fit your specific needs. We recommend reviewing all generated code before deploying to production environments.

What AI models are available?

Currently, we support three AI models: Meta Llama 3 70B (recommended for most use cases), Llama 4 Maverick, and Meta Llama 3.1 405B (for advanced requirements). You can switch between models in the model selector dropdown on the main page.

How do I report a bug or issue?

You can report bugs or issues using the contact form on this page. Please include as much detail as possible, including the steps to reproduce the issue, your browser information, and any error messages you received. Our team typically responds within 24 hours.
